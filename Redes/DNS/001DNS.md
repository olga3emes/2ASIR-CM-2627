# Práctica: Configuración de una Red LAN con Servidor DNS

## Objetivos

- Configurar una red LAN.
- Configurar un router.
- Configurar un servidor DNS.
- Asociar nombres de dominio con direcciones IP.
- Comprobar la resolución de nombres mediante pruebas de conectividad.

---

## Topología de Red

```text
                    Red 192.168.1.0/24

PC0        PC1
 |           |
 +-----------+
       |
       |
      R1
 G0/0 | 192.168.2.1
       |
       |
 G0/1 | 192.168.1.1
       |
       |
  Servidor DNS
  192.168.1.2
```

---

## Configuración de la Red

### Router R1

- G0/0: 192.168.2.1 / 255.255.255.0
- G0/1: 192.168.1.1 / 255.255.255.0

### Servidor DNS

- IP: 192.168.1.2
- Máscara: 255.255.255.0
- Gateway: 192.168.1.1

---

## Configuración de los Equipos Cliente

### PC0

- Dirección IP: 192.168.2.10
- Máscara: 255.255.255.0
- Gateway: 192.168.2.1
- DNS: 192.168.1.2

### PC1

- Dirección IP: 192.168.2.20
- Máscara: 255.255.255.0
- Gateway: 192.168.2.1
- DNS: 192.168.1.2

---

## Explicación de la Configuración

### Router

El router R1 conecta las redes 192.168.2.0/24 y 192.168.1.0/24, permitiendo la comunicación entre ambas.

### Servidor DNS

El servidor DNS traduce nombres de dominio a direcciones IP.

Ejemplo:

```text
servidor.local -> 192.168.1.2
```

### Equipos Cliente

Los equipos utilizan como puerta de enlace 192.168.2.1 y como servidor DNS 192.168.1.2.

---

## Configuración del Servicio DNS

Ejemplo de registros:

- servidor.local → 192.168.1.2
- web.local → 192.168.1.100
- ftp.local → 192.168.1.101

---

## Pruebas de Funcionamiento

### Comprobar conectividad con el router

```bash
ping 192.168.2.1
```

### Comprobar conectividad con el DNS

```bash
ping 192.168.1.2
```

### Comprobar la resolución DNS

```bash
ping servidor.local
```

### Verificar mediante nslookup

```bash
nslookup servidor.local
```
